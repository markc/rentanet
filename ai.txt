## The Cosmix Stack

Every hosting plan is a lightweight Proxmox container running Cosmix, an all-Rust service
stack designed from the ground up to be operated by AI agents.

- JMAP + IMAP mail server in a single Rust daemon
- Built-in web serving with automatic TLS; CMS pages, blog, forum, file manager
- Webmail, contacts and calendar (PIM) included
- Authoritative DNS, API-driven
- AMP agent mesh — every service is agent-addressable
- Mix shell — scripting built for AI operators

- Administered end-to-end by Claude Code
