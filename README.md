# RentaNet

The [renta.net](https://renta.net) website: a static site generated by a Mix
script. Australian managed Linux hosting, business email, Linux support and
AI-assisted development.

## Layout

| Path | What |
|---|---|
| `build.mix` | The generator and all page copy. Writes `dist/`. |
| `deploy.mix` | Build, rsync to the web server, refresh the `/` handler, purge the CDN. |
| `serve.mix` | Local preview of `dist/` on http://127.0.0.1:8099. |
| `assets/` | `site.css`, `site.js`, `theme.js` and self-hosted fonts. Published under `/rn/`. |
| `static/` | Copied to the web root as is: `favicon.ico`, `ai.txt`. |
| `webd/home.mix` | The webd handler that serves `/` with security headers. |
| `deploy.conf.example.mix` | Template for the local, untracked `deploy.conf.mix`. |

## Use

```
mix build.mix && mix serve.mix     # preview
mix deploy.mix                     # publish
```

Prices, plan sizes and the technology strip are data at the top of
`build.mix`. The capacity calculator on the pricing page uses the same
formula as the plans: $19/year base plus $20/year per resource unit.

## Notes

- **No inline scripts or styles.** The home page is served with a strict
  Content-Security-Policy (`script-src 'self'; style-src 'self'`), so
  animation delays are classes and the theme is set by `theme.js`.
- **Assets live under `/rn/`**, not `/assets/`: the web server keeps its own
  shared files at `/assets/` and they take precedence.
- Light and dark themes share one set of CSS custom properties; the toggle is
  in the top right and the choice is kept in `localStorage`.
- All motion is switched off under `prefers-reduced-motion`.
- The pre-2026-11 site (hand-written HTML with `base.css`/`site.css`) is in
  the git history.
